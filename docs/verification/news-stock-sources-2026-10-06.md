# News stock-source dropdown

The Web News screen now has one **Stock source** dropdown, separate from **News provider** and **Publisher / source**. It contains All news/all stocks, All wishlist stocks, All Finviz stocks, All wishlist + Finviz stocks, My positions, each ordinary wishlist, each locally saved Elite screen, and catalogue swing/Finviz screens. The existing Ticker field selects one exact stock within the chosen source. Selecting a source filters stored articles; it does not start news collection.

“All Finviz stocks” means all stocks returned by the `ind_stocksonly` screen, rather than a union of saved-screen results. A clarification was offered and this default was stated while proceeding. Individual saved screens retain their own filters. Complete returned `AllSymbols` are used, including members beyond the 250-stock public preview and 50-row desk window. Ordinary wishlist union excludes inactive items, historical preparation revisions and unlisted account holdings. Combined membership is deduplicated. Finviz membership/count/observation time is described as current, not historical.

The shared query API accepts `stockSource`; legacy `groupId` and `scope=groups/positions` links remain supported, normalize to the same selection, and conflicting selections are rejected. Chosen source, ticker and article filters survive Apply/reload/paging; Clear returns to All news. Unknown/deleted sources and malformed query identifiers return 400. Private source requests without sign-in return 401 rather than silently broadening to public news; default public All news makes no private membership/account/provider reads.

Desk and News share one Finviz observation per query, with serialized reads, a 15-second cancellation deadline, one-minute successful cache and five-second provider-failure/timeout cache. Caller cancellation remains uncached; a timeout waiting for another read does not poison that query. Finviz failure or incomplete membership leaves the selected scope unavailable, including combined membership. A successful empty screen remains a legitimate empty result. No broker action, strategy grant, Android change, operational data reset or GitHub push occurred.
