Mixed/opposing clauses, unbound subjects, unsupported categories and oversized model text remain Unknown. No new event families, trading indicators, exits, risk settings or optimized thresholds.

Old version 1 published assessments retain their original recomputation. A version 2 package can contain version 1 literal-ticker fallback rows only where no unique name mapping exists; version 1 packages cannot acquire mapped version 2 rows. The shared evaluator and verified package reader enforce the same allowed version pairs.

Web/API/Android sample views also show the official company name, provider and actual capture time. Captures made in October do not prove which name was known at an old trade. These remain retrospective measurements; human semantic accuracy is unmeasured.
