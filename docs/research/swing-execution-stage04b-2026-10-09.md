# Stage 04B frozen execution policy

Execution policy `daily-rth5m-nextslice-ioc-v1` is a separate run parameter, not a strategy change. Run exactly cycle03 RSI5 and MR broad-stretch/SMA5 at their original 10/20bps costs across the five original cohorts. Keep canonical strategy identities, daily SIP/all series, symbol-asof 2026-10-07, April 7 through October 6 study, 260-bar daily warmup, late-listing exclusions, risk, fees and ranking. No outcome-driven parameter search.

Supported capabilities are daily long strategies without trailing or sub-daily confirmation. Daily evidence alone sets signals, stops and technical/time exits. Entry day remains skipped for daily exit evaluation; the next eligible daily bar has held count one. A daily technical exit is actionable only after that native daily bar's frozen availability, then mapped to the next authoritative session open. Daily protective touches never truncate this exit horizon. The shared execution book independently observes five-minute protection.

Execution uses full regular-session native five-minute slices, including the last thirty minutes. Daily source-session entry and exit intents map to authoritative session opens. Entry is an opening-slice IOC proxy: a completed five-minute slice supplies opening price and participation capacity; the known filled quantity receives protection starting on the following eligible slice. Unfilled entry quantity is canceled. The first slice is explicitly unprotected, which is not necessarily pessimistic for returns. No within-slice path or immediate bracket activation is inferred.

Already-active stops take adverse precedence over targets on ambiguous slices; stop gaps use the opening-price proxy. Activated stop remainders stay activated. Protective quantities and OCO ownership follow known fills. Technical exits cancel protection and liquidate the remaining quantity. Fees and liquidity are shared by the chronological book. October 6 daily terminal source maps to its regular open; only prior completed-slice volume supplies capacity for that opening-point proxy. Remaining quantity at the terminal opening step makes economics incomplete; no later liquidation is allowed.

Required missing, duplicate, invalid or zero-volume slices while an order/position is active make the treatment incomplete. Do not substitute stocks, suppress signals using future gaps, manufacture candles, move a missing opening to 09:35, or report incomplete results as zero returns. Capture full study coverage for all eligible cohort members and SPY daily; compare canonical daily content hashes to cycle03 before execution. Preserve failure evidence and prefix fills.

Monthly valuation samples the original daily source-session close grid, processing intervening five-minute fills. Report marked-to-market monthly returns and close drawdown by exact strategy/version/hash, cost and cohort; label April/October partial. Show changes from the original daily baseline only for complete treatments. Original setup decisions and daily stop evidence must reconcile. Changes can arise from protection, IOC fills, execution prices and subsequent capital/slot availability.
